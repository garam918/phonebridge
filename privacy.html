시행일 2026년 10월 27일 · PhoneBridge for Mac

PhoneBridge는 어떤 데이터도 외부로 보내지 않습니다. 서버, 회원 가입, 사용 통계 수집, 광고, 자동 오류 보고가 없습니다. 앱에는 네트워크 권한이 없어 macOS 샌드박스가 인터넷 연결을 막습니다. 개발자는 사용자의 어떤 정보도 받지 않습니다.

앱이 다루는 정보

아래 정보는 모두 사용자의 Mac 안에서만 처리되며, 외부로 전송되지 않습니다.

시스템 기록(로그)

  • 문제 진단을 위해 macOS 통합 기록(Unified Log)에 앱 동작을 남깁니다. 이 기록은 Mac 밖으로 나가지 않습니다.
  • 파일·폴더 이름, 기기 이름, Mac 경로는 "비공개" 값으로 기록되어 macOS가 <private>로 가립니다. 기기 일련번호가 포함된 식별자는 해시로만 기록됩니다.
  • 기기 모델명, USB ID, 오류 코드, 바이트 수, 시간은 그대로 기록됩니다.

진단 정보 내보내기

도움말 › 진단 정보 내보내기는 사용자가 고른 위치에 텍스트 파일 하나를 만듭니다. 앱이 자동으로 보내지 않으며, 사용자가 직접 문의에 첨부할 때만 전달됩니다. 파일·폴더 이름은 들어 있지 않고, 일련번호는 짧은 해시로만 들어갑니다. 첨부하기 전에 파일을 열어 내용을 확인할 수 있습니다.

휴대전화에 남기는 것

PhoneBridge는 휴대전화에 앱을 설치하지 않습니다. 파일을 올리거나 덮어쓰는 동안에만 .phonebridge-로 시작하는 숨김 임시 파일을 만들고, 끝나면(또는 다음 연결 때) 지웁니다.

이 웹사이트

이 웹사이트는 GitHub Pages로 운영되며 쿠키, 방문 분석 도구, 외부 글꼴을 사용하지 않습니다. GitHub는 사이트 운영을 위해 방문자의 IP 주소를 기록할 수 있습니다(GitHub 개인정보 처리방침).
