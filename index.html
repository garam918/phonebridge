Android 파일을
Finder처럼 간편하게

USB로 연결한 Android 휴대전화·태블릿의 사진, 동영상, 문서를 Mac에서 바로 탐색하고 옮길 수 있는 macOS 앱입니다.

Mac용 내려받기 다른 설치 방법

무료오픈소스(MIT)Apple 공증 완료macOS 15 이상Apple Silicon

필요한 기능만, 익숙한 방식으로

휴대전화에 따로 앱을 설치할 필요가 없습니다. 케이블을 연결하고 '파일 전송'만 선택하면 됩니다.

연결 상태 안내

연결이 안 될 때 USB 모드, 화면 잠금, 다른 프로그램 사용 중 등 원인과 해결 방법을 알려 줍니다.

익숙한 탐색

Finder처럼 폴더를 오가며 정렬, 검색, 썸네일, 훑어보기(Quick Look)를 사용할 수 있습니다.

안전한 전송

Mac과 Android 사이에서 양방향으로 파일을 옮깁니다. 같은 이름의 파일을 덮어쓸 때도 새 파일이 다 옮겨지기 전에는 원본을 지우지 않습니다. 진행률 확인, 취소, 재시도도 지원합니다.

Finder로 끌어다 놓기

PhoneBridge 창의 파일을 Finder나 데스크톱으로 끌어다 놓으면 바로 복사됩니다.

Finder 사이드바 연결macOS 26+

휴대전화 저장공간이 Finder 사이드바의 '위치'에 나타납니다. 실수로 지우는 일이 없도록 기본은 읽기 전용입니다.

한국어 · English

한국어를 기본으로 지원합니다. 설정에서 영어로 바꾸면 앱을 다시 열지 않아도 바로 적용됩니다.

연결하면 바로 열기

설정에서 켜 두면 휴대전화를 꽂을 때 PhoneBridge가 자동으로 열립니다. 기본은 꺼져 있습니다.

iPhone·iPad 사진시험 단계

iPhone·iPad의 사진과 동영상을 보고 Mac으로 가져오거나 지울 수 있습니다. 아직 실제 기기로 검증하지 않은 기능입니다.

어떤 데이터도 외부로 보내지 않습니다

회원 가입, 광고, 사용 통계 수집, 자동 오류 보고가 없습니다. 앱에 네트워크 권한이 없어 macOS가 인터넷 연결 자체를 차단합니다. 시스템 기록에도 파일 이름과 기기 일련번호를 남기지 않습니다.

설치

편한 방법을 선택하세요. 어느 방법이든 Apple 공증을 받은 같은 앱이 설치됩니다.

DMG

내려받은 PhoneBridge.dmg를 열고 PhoneBridge를 응용 프로그램 폴더로 끌어다 놓으면 설치가 끝납니다.

PhoneBridge.dmg 내려받기

이전 버전과 변경 사항은 릴리스 페이지에서 볼 수 있습니다.

터미널

체크섬, 개발자 서명, Apple 공증을 모두 확인한 뒤에만 설치합니다.

curl -fsSL https://github.com/garam918/phonebridge/releases/latest/download/install.sh | bash

관리자 권한 없이 ~/Applications에 설치하려면 명령 끝에 -s -- --user를 붙이세요.

Homebrew

Homebrew 7 이상에서는 처음 한 번 이 저장소를 허용(trust)해야 합니다.

brew trust --cask garam918/phonebridge/phonebridge
brew install --cask garam918/phonebridge/phonebridge

필요한 환경

  • Apple Silicon(M1 이상)을 탑재한 Mac
  • macOS 15 Sequoia 이상
  • Finder 사이드바 연결은 macOS 26 이상 필요 (이전 버전에서도 PhoneBridge 창에서 나머지 기능을 모두 사용할 수 있습니다)
  • 데이터 전송을 지원하는 USB 케이블 (충전 전용 케이블로는 기기가 인식되지 않습니다)
  • 휴대전화의 USB 사용 목적을 파일 전송으로 설정
