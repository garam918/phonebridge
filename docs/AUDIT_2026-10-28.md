## 1. 높음

### H1. 커진 파일의 조각 다운로드가 잘린 채 검증을 통과하고, 이동이면 원본이 삭제됨 (데이터 손실, **확인** — 이전 M6)
- `PBMTPBridge.c:557`(`pb_get_object`), `DeviceFileSystem.swift:84, 108-113`, `TransferManager.swift:319-321, 260-261`
- libmtp는 비캐시 모드에서도 한 번 읽은 객체 메타데이터를 세션 동안 `params->objects`에 보관하고(`ptp.c:8951-8953` "Do we have all of it already?"), 이름 변경·업로드·EndEdit 외에는 갱신하지 않는다. `LIBMTP_GetPartialObject`는 요청 범위를 **캐시된 크기**로 자른다(`libmtp.c:9241-9247`).
- 시나리오: 파일을 한 번 본 뒤 휴대전화에서 커진 경우(촬영 중인 동영상, 받는 중인 파일, 32 MiB 이상). 앱이 `item(id).size`로 옛 크기를 얻어 그만큼만 조각으로 받고, 크기 검증도 같은 옛 크기와 비교하므로 **통과**. 잘라내기(이동)면 원본을 지운다. 전체 객체 경로(`GetObject`)는 실제 바이트가 달라 검증에 실패하므로 안전 — 이 문제는 부분 읽기 지원 기기(현대 Android 전부) + 32 MiB 이상 파일에 한정된다.
- 수정: 브리지에 캐시 제거 호출 추가(`ptp_remove_object_from_cache`는 `libmtp.h`에 없음 → `ptp.h`를 브리지에서 포함하거나 vendored 빌드에서 export). 다운로드 시작 전과 `SafeDeviceWrite` 검증 전에 호출. 최소 완화: 이동(`deleteSource`)은 전체 객체 다운로드로 받고 새 ObjectInfo로 검증.

## 4. 확인 결과 문제없음
- **피어 검증(D62)**: 요구 조건 문자열은 자기 번들 ID·자기 서명 팀으로만 만들어지고, 따옴표가 섞이면 파싱 실패로 거부(fail-closed). 감사 토큰의 **동적** 코드에 `SecCodeCheckValidity`. cdhash 경로는 ad-hoc 빌드에서만. 해제 헬퍼 요구 조건에 팀 포함.
- **설치 스크립트의 인증서 요구 조건**(`install.sh:98`): `anchor apple generic` + Developer ID 중간 CA OID + Developer ID Application 리프 OID + 팀. Apple Development·다른 팀 통과 불가. 마운트본 검증 → `ditto` → 스테이징 **재검증** 순서 확인(앱 수준 TOCTOU 없음). sudo·격리 해제·Gatekeeper 변경 없음. 다운로드는 `--proto '=https' --tlsv1.2`.
- **런처**: IORegistry 읽기만(user client·I/O 없음), 파일 쓰기 없음, 자기 번들 밖 코드 실행 없음, `openApplication(at:)`은 자기를 감싼 번들만. 등록은 사용자 토글(+ 진단 스위치)뿐.
- **기기 이름 → Mac 경로**: `singleComponent`가 MTP·ImageCapture 양쪽 경계에 적용되고, Mac 쓰기 지점 전부 `LocalFileIO.child/descendant` 경유(D64 유지).
- **iPhone 삭제**: 선택한 트리만, 폴더는 지우지 않음, 거부된 파일이 하나라도 있으면 실패(D80), 건너뛴 파일이 있는 계획은 삭제하지 않음.
- **C 브리지**: `pb_count_children` 메모리 해제, 오류 스택 최신 항목 선택, 이중 해제 없음, fd 소유권, 진행률 콜백 수명, `pb_open` 직렬화. 조각 업로드는 `EndEditObject`가 캐시를 갱신해 검증이 정확함(H1과 대비).
- **IPC 프레임**: 길이 상한 후 할당, 큰 응답은 본문, 전송 오류 뒤 재연결(M1 수정 유지), 비멱등 요청 재전송 없음. 버퍼 이름은 확장이 만든 UUID + 앱 쪽 `isValidBufferName`.
- **진단 보고서**: 기기 ID 해시, Apple 기기는 종류·상태만, 전송은 개수·바이트·키만, 로그는 현재 프로세스·앱 subsystem만, `/Users/<name>` 제거. 저장 패널로만 기록.
- **웹사이트**: 인라인 스크립트·핸들러·폼·iframe·외부 자원 없음, http→https 301, HSTS.
