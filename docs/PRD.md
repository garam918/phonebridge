# PhoneBridge PRD

## 1. 목적

Android 스마트폰·태블릿을 USB로 Mac에 연결하면 기기 내부 파일을 탐색·관리할 수 있는
macOS 네이티브 앱. 한국 사용자가 1차 대상이며 한국어가 기본, 영어를 함께 지원한다.

최종적으로 두 가지 인터페이스를 제공한다.

1. 전용 macOS 파일 탐색기 (Finder와 비슷한 학습 부담)
2. Finder에 Android 저장소 마운트 (FSKit, 후속 단계)

## 2. 대상 환경

- macOS 26 이상, Apple Silicon 우선
- Android 기기의 MTP(“파일 전송”) 모드

## 3. 단계별 범위

| 단계 | 내용 | 상태 |
|---|---|---|
| 1. 기반 | Xcode 프로젝트, SwiftUI 탐색기 골격, Mock 기기, 한/영 현지화, 테스트 | 완료 |
| 2. MTP 탐색 | IOKit USB 감지, libmtp/libusb 브리지, DeviceBroker, 연결 상태, 읽기 전용 탐색 | 완료 (실기기 검증 대기) |
| 3. 파일 관리(2차 개발) | 양방향 전송, TransferManager, 폴더 생성·이름 변경·삭제·복사·이동, 다중 선택, 드래그 앤 드롭, 검색, 미리보기, Android/Mac 2분할 | 완료 (실기기 검증 대기) |
| 4. 고도화 | 썸네일 그리드, 전송 병렬화(기기별), 경로 복원, 대용량 폴더 점진 표시 | 예정 |
| 5. Finder 통합 | FSKit 모듈, 마운트/해제, 캐시 | 예정 |
| 6. 배포 | 서명/공증, LGPL 준수 패키징, 자동 업데이트 검토 | 예정 |

## 4. 2단계 기능 요구사항 (이번 단계)

- R1 IOKit으로 USB 기기 연결/해제를 앱 실행 중 실시간 감지
- R2 USB 장치 중 MTP 장치를 USB 디스크립터로 구분 (MTP / 충전 전용 / PTP / iPhone·카메라 / 무관한 기기)
- R3 libmtp + libusb 네이티브 통합, Swift에서 쓰는 C 브리지
- R4 MTP 세션 시작/종료, 기기 정보·저장소 목록·폴더 목록·파일 메타데이터 조회
- R5 MTP/USB 오류를 Swift `DeviceError`로 변환, UI에 현지화된 사유 표시
- R6 USB 해제 시 안전한 세션 정리, UI가 오류 없이 복구
- R7 연결 상태: `disconnected`, `usbDetected`, `waitingForMTP`, `connecting`, `connected`, `reconnecting`, `failed`, `unsupported`
- R8 USB 연결 성공과 MTP 접근 성공을 화면에서 구분 (체크리스트 2단)
- R9 Android 파일 전송 모드 선택 안내 (한/영), 잠금 해제 안내
- R10 다른 MTP 프로그램과의 접근 충돌 원인 설명 (프로세스를 임의로 종료하지 않음)

## 5. 비기능 요구사항

- MTP 세션은 `DeviceBroker`만 관리, UI는 libmtp를 직접 호출하지 않는다.
- 장치별 MTP 작업 직렬화, 메인 스레드에서 블로킹 I/O 금지.
- 파일 ID는 (기기, MTP 저장소 ID, MTP 객체 핸들)과 세션 세대(generation)를 고려한다.
- 실제 기기 작업과 Mock 작업을 UI와 코드에서 명확히 구분한다.
- 불필요한 외부 의존성 금지 (런타임 의존성은 libmtp, libusb만).
- 사용자의 macOS 보안 설정을 임의로 바꾸지 않는다.

## 6. UI 원칙

- Apple HIG 기반 네이티브 디자인, 라이트/다크 모드, SF Symbols
- 사이드바(기기 → 저장소), 목록/아이콘 보기, 경로 막대, 정보 패널(Inspector), 하단 상태 막대(전송 영역)
- 불필요한 애니메이션 배제, 한국어 기준의 자연스러운 용어(“내부 저장공간”, “파일 전송”, “다시 시도”)
- 설정에서 한국어/영어 선택, 재실행 없이 앱 화면 언어 전환

## 7. 3단계(2차 개발) 요구사항 — 파일 관리

| # | 요구 | 구현 위치 |
|---|---|---|
| F1 | Android → Mac 다운로드 (파일·폴더) | `TransferManager.runDownload`, 컨텍스트 메뉴·툴바·⇧⌘D·Mac 패널로 드래그 |
| F2 | Mac → Android 업로드 (파일·폴더) | `runUpload`, 업로드… (⌘U), Finder/Mac 패널에서 드래그, Finder에서 ⌘C 후 ⌘V |
| F3 | 폴더 단위 전송 (빈 폴더 포함) | 원격 트리 walk / 로컬 enumerator |
| F4 | 새 폴더 | 이름 검증 시트 (⇧⌘N) |
| F5 | 이름 변경 | 시트(Return 키), MTP rename 지원 시에만 활성 |
| F6 | 삭제 | 확인 대화상자(되돌릴 수 없음 안내) → 삭제 작업(하위부터) |
| F7 | 복사·이동 | ⌘C/⌘X/⌘V, 기기 내 드래그=이동, 미지원 기기는 Mac 경유 |
| F8 | 다중 선택 | 목록(⌘/⇧ 클릭), 아이콘 보기(⌘/⇧ 클릭) |
| F9 | 드래그 앤 드롭 | Finder→Android, Android↔Mac 패널, 폴더 위로 드롭 |
| F10 | 검색·정렬 | 툴바 검색(현재 폴더 / 하위 폴더 포함), 열 정렬 |
| F11 | 이미지·동영상 미리보기 | Quick Look(Space, ⌘Y), 정보 패널 MTP 썸네일 |
| F12 | 문서 미리보기 | Quick Look 지원 형식(PDF, Office, iWork, 텍스트 등), HWP 등은 비활성 |
| T1 | 전송 대기열·속도·파일별/전체 진행률·취소·실패 사유·재시도 | `TransferManager`, 하단 전송 막대·목록 |
| T2 | 연결 해제 처리, 중복 충돌 처리 | 실패 처리·경로 재해석 재시도, 충돌 시트(대치/둘 다 유지/건너뛰기/모두 적용) |
| S1 | 원본 손실 방지, 덮어쓰기 확인, 임시 파일, 완료 후 검증, 부분 실패 정리 | 스테이징 + 크기 검증 + 백업 이름 교체 |
| S2 | 로컬 경로 권한, 수 GB 파일, 여유 공간 검사, 미지원 기능 비활성 | 보안 범위 북마크, 64비트 스트리밍, 사전 공간 검사, capability 기반 UI |
