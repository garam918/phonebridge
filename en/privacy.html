Privacy Policy

Effective October 27, 2026 · PhoneBridge for Mac

PhoneBridge sends nothing anywhere. There is no server, account, analytics, advertising or automatic crash reporting. The app has no network permission, so the macOS sandbox blocks internet access. The developer receives no information about you.

What the app handles

Everything below is processed only on your Mac and is never transmitted.

System log

  • PhoneBridge writes its activity to the macOS unified log for troubleshooting. The log stays on your Mac.
  • File and folder names, device names and Mac paths are logged as private values, which macOS shows as <private>. Identifiers containing serial numbers are logged only as hashes.
  • Device models, USB ids, error codes, byte counts and times are logged as is.

Export Diagnostics

Help › Export Diagnostics… writes one text file where you choose. Nothing is sent automatically; it reaches anyone only if you attach it to a support request. It contains no file or folder names, and serial numbers only as short hashes. You can open the file and read it before sending.

What is left on the phone

PhoneBridge installs nothing on the phone. It creates hidden temporary files starting with .phonebridge- only during uploads and replacements and removes them afterwards (or at the next connection).

This website

This site is served by GitHub Pages and uses no cookies, analytics or external fonts. GitHub may log visitors’ IP addresses to operate the service (GitHub Privacy Statement).

Removal

Deleting the app and its container folders removes all of the above. See the install and uninstall guide.
