# PhoneBridge 사용 설명서

PhoneBridge는 USB로 연결한 Android 휴대전화·태블릿의 파일을 Mac에서 탐색하고 옮기는 앱입니다. Apple Silicon(M1 이상) Mac, macOS 15 이상에서 동작하고, Finder 사이드바 연결은 macOS 26 이상에서 쓸 수 있습니다. 설치·제거는 `INSTALL.md`, 개인정보는 `PRIVACY.md`를 보세요.

## 1. 연결하기
1. 데이터 전송이 되는 USB 케이블로 기기를 Mac에 연결합니다.
2. 기기 잠금을 풉니다.
3. 기기 알림의 'USB 사용 목적'에서 **파일 전송**을 고릅니다. "휴대전화 데이터에 대한 접근을 허용할까요?"가 나오면 **허용**을 누릅니다.
4. 왼쪽 **연결된 기기** 목록에 기기가 나타나고 내부 저장소가 열립니다.

기기 상태에 따라 안내가 표시됩니다.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 파일 전송 모드를 선택해 주세요 | 충전 전용 모드 | 기기 알림에서 '파일 전송' 선택 |
| 사진 전송(PTP) 모드로 연결됨 | 사진 전송 모드 | '파일 전송'으로 변경 |
| 기기 잠금을 해제해 주세요 | 잠겨 있거나 데이터 접근 미허용 | 잠금 해제 후 '허용' |
| 다른 프로그램이 기기를 사용 중 | 이미지 캡처, Android File Transfer, Smart Switch 등이 기기를 점유 | 해당 프로그램을 종료하고 **다시 시도** |
| 다시 연결 대기 중 | 케이블이 빠졌거나 모드가 바뀌는 중 | 8초 안에 다시 연결되면 이어서 사용 |
| 안전하게 연결 해제됨 | 케이블을 뽑아도 되는 상태 | 케이블 분리 또는 **다시 연결** |

기기가 보이지 않으면 **도움말 › 연결 문제 해결**을 여세요.

## 2. 탐색하기
- 폴더를 두 번 클릭하면 들어갑니다. 뒤로 ⌘[, 앞으로 ⌘], 상위 폴더 ⌘↑, 새로 고침 ⌘R.
- 보기: 목록 ⌘1, 아이콘 ⌘2. 목록의 열 제목을 눌러 이름·수정일·크기·종류 순으로 정렬합니다.
- 이름으로 검색 ⌘F: 현재 폴더 또는 하위 폴더 전체에서 찾습니다(하위 폴더 검색은 최대 2,000개).
- 정보 패널(⌥⌘I): 선택한 항목의 크기·수정일·위치와 사진·동영상 미리보기 이미지.
- 훑어보기 ⌘Y 또는 스페이스: 사진·동영상·PDF·문서를 미리 봅니다(1 GB 이하, 처음 열 때 Mac으로 내려받음).

## 3. 파일 옮기기
| 하려는 일 | 방법 |
|---|---|
| Mac으로 가져오기 | 항목 선택 후 **다운로드**(⇧⌘D, 다운로드 폴더) 또는 **다른 위치에 다운로드…**(⌥⇧⌘D) |
| Finder로 바로 끌어 놓기 | Android 목록에서 Finder 창·데스크탑으로 끌어 놓기. 놓은 뒤 내려받기가 끝나면 파일이 나타남 |
| 기기로 보내기 | **Mac에서 업로드…**(⌘U) 또는 Finder에서 Android 목록으로 끌어 놓기 |
| Mac 패널과 함께 보기 | **Mac 패널 보기**(⌥⌘2): 왼쪽 Android, 오른쪽 Mac. 두 패널 사이로 끌어 복사 |
| 기기 안에서 이동 | 폴더 위로 끌어 놓기, 또는 잘라내기 ⌘X → 붙여넣기 ⌘V |
| 새 폴더·이름 변경·삭제 | ⇧⌘N, 이름 변경…, ⌘⌫(확인 후 삭제, 기기에는 휴지통이 없어 되돌릴 수 없음) |

- 같은 이름이 있으면 **대치 / 둘 다 유지 / 건너뛰기**를 묻습니다.
- 한글 파일 이름은 휴대전화에서 자모가 분리되지 않도록 완성형으로 바꿔 보냅니다.
- 여러 항목을 한 번에 Finder로 끌어 놓으면 전송 목록에 한 줄로 표시됩니다.
- 진행 상황은 창 아래 **파일 전송** 막대에 표시되고, ⌥⌘T로 전송 목록을 엽니다. 실패한 전송에는 원인과 해결 방법이 함께 나오며 **다시 시도**할 수 있습니다.
- 전송 중 케이블이 빠지면 작업은 실패로 표시되고, 기기와 Mac에 덜 옮겨진 파일이 남지 않습니다. 다시 연결한 뒤 다시 시도하세요.
- 앱이 비정상 종료되어 임시 파일이 남으면 다음 실행·연결 때 자동으로 정리합니다.

## 4. 안전하게 연결 해제
**기기 › 안전하게 연결 해제**(⌘E) 또는 사이드바의 기기를 오른쪽 클릭합니다. 진행 중인 전송이 있으면 먼저 묻고, Finder에 연결된 저장소를 해제한 뒤 "이제 케이블을 분리해도 됩니다"를 표시합니다. Finder에서 기기의 파일을 열어 둔 상태면 해제하지 못하므로 파일을 닫고 다시 시도하세요.

## 5. Finder에서 사용하기(선택)
설정 › Finder에서 **Finder 통합 사용**을 켜고 시스템 설정에서 'PhoneBridge Finder' 확장을 켜면, 기기 저장소가 Finder 사이드바의 위치 아래에 나타납니다(`INSTALL.md`).
- 기본은 **읽기 전용**입니다: Finder에서 열기, 훑어보기, Mac으로 복사가 됩니다.
- **Finder에서 쓰기 허용(실험적)**을 켜면 Finder에서 휴대전화로 복사·이름 변경·삭제할 수 있습니다(켤 때 확인 창이 나옵니다). 휴대전화에서 지운 파일은 되돌릴 수 없으니 중요한 파일은 먼저 백업하세요.
- Finder 볼륨을 쓰는 동안 큰 파일 복사가 진행되면 다른 폴더 목록이 잠시 늦게 열릴 수 있습니다(MTP는 한 번에 한 작업만 처리).

## 6. 설정
- **일반 › 언어**: 한국어 / English. 앱 화면은 즉시 바뀝니다. macOS가 만드는 일부 문구(앱 메뉴의 서비스·종료, 파일 열기 창 버튼)는 앱을 다시 실행하면 바뀝니다.

## 7. 문제가 있을 때
1. **도움말 › 연결 문제 해결**의 점검 목록(케이블, 포트, 잠금 해제, 다른 프로그램)을 확인합니다.
2. 해결되지 않으면 **도움말 › 진단 정보 내보내기…**로 텍스트 파일을 저장해 문의에 첨부합니다. 파일·폴더 이름은 들어 있지 않으며, 보내기 전에 내용을 열어 볼 수 있습니다.

## 8. 알아 두면 좋은 제한
- MTP는 한 번에 한 작업만 처리합니다. 큰 파일은 조각으로 나눠 옮겨 그 사이에 다른 폴더를 열 수 있지만, 이를 지원하지 않는 기기에서는 전송이 끝날 때까지 기다릴 수 있습니다.
- SD 카드가 FAT32면 4 GB보다 큰 파일을 보낼 수 없습니다(기기 제한).
- 기기가 잠기면 일부 기기는 저장소를 숨깁니다. 잠금을 풀면 자동으로 이어집니다.
- 실제 기기로 전송까지 검증한 것은 Galaxy S25 Edge(SM-S937N), Finder 연결로 탐색·읽기를 확인한 것은 Galaxy Z Flip5(SM-F731N)입니다. 다른 Android 기기도 표준 MTP를 쓰면 동작할 가능성이 높지만 검증되지 않았습니다.
